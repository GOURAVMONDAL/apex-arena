# APEX Arena

An original browser arena combat racer. Drive, drift, jump, use rockets and bombs, and take on rival cars.

Includes six vehicles, customizable car liveries and drivers, four playgrounds with different scenery and grip, four themes, six challenge missions and free roam, smoke and chassis vibration, synthesized audio, and keyboard, touch and gamepad controls. Reduced effects support motion-sensitive players.

The opening uses the supplied racing artwork with animated smoke, sparks and a camera push. Enter the garage to choose Velo, a purple helmet racer with a digital visor and checkered scarf; Stella, a yellow star racer with a red beanie and star sunglasses; or Ember, the orange kart. These are procedural 3D interpretations of the opening artwork, with animated steering, suspension and wheels. The opening waits for actual initialization and supports skipping motion and reduced-motion preferences.

This public edition stores progress, profiles and personal records in your browser. Clearing browser storage removes those saves. It does not require an account or provide a global leaderboard.

## Play

[Open APEX Arena](https://gouravmondal.github.io/apex-arena/)

WASD or arrow keys drive, Shift boosts, Space jumps, Q fires rockets, E drops bombs, P or Escape pauses, and C switches camera. Enable sound in settings after interacting with the game.

## Development

Requires Node.js 22.13 or newer.

```sh
npm ci
npm run dev
```

Run `npm test` for simulation and motion checks. `npm run build:pages` outputs the static game to `dist-pages/`. Pushes to `main` publish through GitHub Actions to GitHub Pages.

Game models, visual effects and sounds are generated by the game's code. The title-screen artwork was supplied by the project owner. Inspired by Awards Racing; its source code is not included.


## Multiplayer and vehicle selection

Choose Velo, Stella, Ember, Dune, Glacier, or Spectre in the garage. Vehicles have distinct driving presets; Dune adds a trail roll cage, Glacier has wide bodywork, and Spectre has an aero wing.

Choose **Multiplayer → Create room**, then have friends scan the QR code with their phone camera or open the copied invitation. Two to four players can join. Each player chooses their vehicle; the host chooses the environment and starts a three-minute arena score round. Highest score wins; live cars, names and scores are shared. The host must keep the tab open. Use the Room button for scores and rematches, or Leave room to return to single player.

This is casual peer-to-peer score competition: player cars pass through each other; AI, pickups and destruction run locally from the same starting seed. It is not an authoritative PvP combat server or a cheat-resistant leaderboard. PeerJS Cloud provides connection signaling; gameplay uses WebRTC data channels. Some restrictive networks may block direct connections; the UI reports connection failures so players can retry on another network. QR generation runs locally without sending invite links to an image service.
